
必做步骤：
# 1. 写代码前，拉取最新代码（防止冲突）
git pull origin dev

# 2. 写你的代码...

# 3. 提交代码
git add .
git commit -m "【你的名字】完成XX功能"
git push origin dev

关于vim编辑器：
方法 1：直接写提交信息并保存退出（推荐）
按键盘上的 i 键，进入编辑模式（左下角会出现 -- INSERT --）
在第一行输入你的提交信息，比如：
plaintext
【洪欣欣】修改了ai-vpr-ser/notes.txt
按 Esc 键退出编辑模式
输入 :wq 然后按回车（:w 保存，:q 退出）
这样就完成提交了，终端会显示提交成功的信息。
方法 2：直接放弃这次提交（不想写了）
如果不想提交了，直接输入 :q! 然后按回车，就会退出编辑器，取消这次提交。
